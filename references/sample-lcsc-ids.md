# 示例：实测用过的 17 个料号（某 SLIC 接口板项目）

> 用途：回归测试与 `--ids-file` 输入样例。
> 数据来源：`pitfalls.md` 附录 A（2026-10-18 实测，17/17 转换成功）。
> 注意：这些料号对应某 SLIC 接口板项目，别处不要直接复用；换项目请自建表。

## 一、可直接当 `--ids-file` 用

每行一个料号，`#` 后为注释；`build_kicad_lib.py --ids-file` 会跳过空行与 `#`。

```
C5754991        # 1x11 排针 2.54（代表 KS0835F SLIC 模块）
C9900010030     # 1x2 排针（J1 12V / JP1 PD）
C9900010031     # 1x3 排针（J3 音频）
C9900010184     # 1x4 排针（J2 控制 / 光耦模块）
C9900020346     # RJ11 6P4C（J4 话机）
C55019967       # B1205S-3WR3 隔离 DC-DC 12V→5V 3W
C9900292356     # EE19-600:600-3+3 音频隔离变压器
C17513          # 0805 1kΩ
C17414          # 0805 10kΩ
C17514          # 0805 1MΩ
C48970781       # 470µF/10V 电解（无 3D 模型）
C28233          # 0805 0.1µF
C2680605        # JK250-050U 500mA PTC
C2831634        # JK250-120U 1.2A PTC
C434967         # P6KE82A 82V TVS
C2128           # 1N4148WS
C130469         # PC817X2NIP0F 光耦
```

## 二、引脚名显示真值样例（逐引脚测试用）

| 料号 | 元件 | EasyEDA `name.is_displayed` | 本技能处理结果 |
|---|---|---|---|
| C2128 | 1N4148WS（A/K） | 全部 False | 符号级隐藏（全隐藏） |
| C55019967 | B1205S-3WR3（+VIN/-VIN/+VOUT/-VOUT） | 全部 True | 符号级显示 |
| C434967 | P6KE82A（A/C） | 全部 False | 符号级隐藏 |
| C130469 | PC817X2NIP0F（AN/CA/COL/EM） | 全部 False | 符号级隐藏 |
| C17513 | 0805 1kΩ（1/2） | 全部 False | 符号级隐藏 |

> 前两行已用 `fix_symbol_pin_names.py --fetch C2128 C55019967` 实测（2026-10-21）：
> `1N4148WST4` 判定"EasyEDA 全隐藏"，`B1205S-3WR3` 判定"EasyEDA 全显示"，
> 与 `pitfalls.md` 附录手测一致；转换结果经 `kicad-cli sym upgrade` exit=0。
